Silero VAD
==========

The model in this directory (`silero_vad.onnx`) is Silero VAD v5.1.2, from
https://github.com/snakers4/silero-vad (tag v5.1.2, file
`src/silero_vad/data/silero_vad.onnx`).

It is pinned by sha256 in `scripts/prepare-vad.mjs`, which `npm run dev` and
`npm run build` both check. Do not replace it with the copy on the `master`
branch: that file is byte-for-byte a different model of the same size, and it
scores 0.0031 on genuine speech -- indistinguishable from silence -- where
this release scores 0.9998.
