# نبرة — موجّه الصوت

تطبيق Electron يلتقط المايك الأصلي، يعالج الصوت بحسابات تكيّفية، ثم يرسل الناتج إلى مايك وهمي تثبّته أنت على ويندوز أو ماك.

## التشغيل للتطوير

```bash
npm install
npm run dev
```

## الفحص

```bash
npm test         # محرّك الطور + دقة كشف النغمة وخط الإزاحة والسلم والإعدادات
npm run lint
npx tsc -b
```

`npm test` لا يحتاج متصفحاً: يشغّل `scripts/pv-test.cjs` على محرّك الطور في ملف
مستقل — بما فيها إشارة عمل `AudioWorklet` كاملة تحاكي ما يفعله المتصفح، ودقة
النغمة عند النسب الكسرية (نصف خطوة، خطوة، خُمس) لكلا إعدادي FFT — ثم
`scripts/dsp-test.mjs` على وحدات نقية (`yin` و`notes` و`offset` و`impulse`
و`devices` و`settings` و`presets`).
قياس كلفة الكاشف **نسبي** (مقابل حلقة مرجعية في العملية نفسها) حتى لا تتأثر
نتيجة الجهاز المحموم.

> النسب الصحيحة (1، 2، 0.5…) لا تكشف أخطاء محرّك الطور: خطأ في إشارة الـFFT
> يختفي عندها ويظهر كخطأ نصف دورة عند أي نسبة كسرية. لذلك يغطي الاختبار النسب
> الكسرية صراحةً.

### خطّ الإزاحة

العدّادات تُشتق من **الإزاحة المطبَّقة فعلاً** لا من الكاشف، فيصير
`النسبة = 2 ** (الإزاحة / 12)` بالضرورة. كان الوضع الثابت يحسب الإزاحة من
`targetMidi` المتروّك من الوضع التكيّفي، فيُعلن «‎1.189×‎ و‎+300 سنت» وحين
التطبيق ما زال على 1.000×؛ وصار عدّاد الضبط في الوضع الثابت يقيس انحراف الصوت
عن أقرب نصف درجة (كاشف حقيقي) بدل إشارته إلى هدف غير موجود.

تتبّع الكاشف يجري في **مجال السنتات** لا في مجال الهرتز، فيكون تأخّره عدداً
ثابتاً من السنتات عند كل النغمات؛ ومرشّح على الهرتز كان يتأخّر نحو خمس مرات
أكثر في صوت منخفض مقابل صوت عالٍ عند أوزان واحدة. ويقود محرّك الطور عاملَ تمدّده
نحو واحدٍ مع التخفيف الجانبي، فلا يستأنف من نسبة قديمة بعد ترك المقبض.

### ذيل الصدى

يُبنى دافعُ الصدى على خيط الواجهة في كل مرةٍ يتحرّك فيها شريطُ الزمن، وكان كل عيّنة تستدعي
`Math.pow`: **12.5 مللي ثانية** لأربع ثوانٍ على مسارين — أكثر من إطارٍ كامل بمعدّل
ستّين، فكان سحب الشريط يُسقط إطارات. صار الغلاف يُقرأ من جدولٍ جاهز
(1024 نقطة، ودقّة الاستيفاء الخطّي ‎3e-7‎) فينزل البناء إلى **1.6 مللي ثانية**.

> صيغةُ الجداء المتراكم `env *= (1 - 1/L) ^ p` أرخصُ وأقربُ إلى البديهة، لكنها
> **ليست** بديلاً: هي منحنى هندسي يحاكي منحنى قُوى، فتترك آخر 5٪ من الذيل **380
> مرّةً أعلى** بصوتاً — أي صدى لا يموت. الاختبار يقارن عيّنةً بعيّنة بالصيغة
> المغلقة القديمة لهذا السبب بالذات.

### ترتيب الإشارة

```
مايك → مرشّحات → دخل → مضخّم → تتبّع مستوى → بوابة → إزاحة (رطب/جاف)
     → طبقة → نغمة → ضغط ─┐
     └─ تشويه/صدَى/طنين/صدى ┴→ حوض المؤثّرات → محدّد → مستوى الخرج → مخرَج
```
المحدّد موضوع **بعد** حوض المؤثّرات كلّها: كان سابقاً بين المزيج وحوض
المؤثّرات، فلم يكن يقيّد حاصل الجَمع إطلاقاً وقصّ الصوت داخل المايك الوهمي.

## الاستخدام

1. ثبّت مايكاً وهمياً جاهزاً:
   - ويندوز: [VB-Audio Virtual Cable](https://vb-audio.com/Cable/)
   - ماك: [BlackHole](https://existential.audio/blackhole/)
2. افتح نبرة واضغط **السماح وتحميل الأجهزة**.
3. **الإدخال**: مايكك الأصلي.
4. **الإخراج**: المايك الوهمي (`CABLE Output` على ويندوز، أو `BlackHole` على ماك).
5. اضغط **ابدأ التوجيه**.
6. في ديسكورد أو زووم اختر طرف الإدخال للمايك الوهمي (`CABLE Input` أو `BlackHole`).

الوضع **تكيّفي** يعيد حساب الإزاحة كلما تغيّر صوتك ليبقى الناتج على النغمة المطلوبة.

## بناء نسخة للتثبيت

```bash
npm run dist:win        # ويندوز 64-بت (x64)
npm run dist:win:arm64  # ويندوز Arm64
npm run dist:mac        # ماك Apple Silicon
npm run dist:mac:x64    # ماك Intel
npm run dist:linux      # لينكس x64
```

الناتج يظهر في مجلد `release/`.

## استكشاف الأخطاء

- **«التطبيق لا يعمل» بعد التثبيت**: تأكد من معمارية جهازك.
  - الحزمة `Nabra-Setup-...-x64.exe` تعمل على معظم أجهزة الويندوز.
  - `...-arm64.exe` مخصصة لأجهزة Snapdragon/Family تؤمن Windows ARM.
  - افحص ملف الأخطاء `%APPDATA%/Nabra/nabra-error.log` (ويندوز) أو `~/Library/Application Support/Nabra/nabra-error.log` (ماك) — يُكتب فيه أي خطأ فوري عند التشغيل. (اسم المجلد يتبع `productName` في `package.json` أي `Nabra`، وليس `nabra`.)
- **SmartScreen في ويندوز**: الحزم غير موقّعة رقمياً، اضغط **More info** ثم **Run anyway**.
- **ماك «لا يمكن فتحه لأنه من مطوّر غير معروف»**: انقر بزر الفأرة الأيمن على التطبيق ثم **Open**، أو من إعدادات النظام → الخصوصية والأمان → **فتح على أي حال**.
- **لا صوت في ديسكورد**:
  - تأكد من اختيار `CABLE Output` / `BlackHole` كمخرج *هنا*، وليس `CABLE Input`.
  - في ديسكورد/زووم اختر `CABLE Input` / `BlackHole` **كالميكروفون**.
- **ظهور تنبيه «إخراج افتراضي»**: فشل الربط المباشر بجهاز المخرج؛ اجعل الكابل الوهمي هو **جهاز الإخراج الافتراضي** في إعدادات الصوت بالنظام ثم أعد تشغيل التوجيه.
- **المايك لا يُفتح**: تأكد أن لا برنامج آخر يستخدم المايك بالوضع الحصري، واسمح بالوصول إلى الميكروفون.
- **الفصل/قطع مفاجئ**: قم بالتحديث من قائمة الأجهزة ثم أعد التوجيه. لوحة «تشخيص المسار» داخل التطبيق تعرض حالة الدخل والخرج والربط مباشرة.

## البنية التقنية والقيود

- التطبيق يبني على **Web Audio API** بالكامل (التقاط، معالجة، إخراج).
  - الميزة: توزيع سريع ودعم تلقائي للأنظمة.
  - القيد: زمن الاستجابة مقيد بمعدّل معالجة المتصفح/إلكترن، وهو أعلى من المسار الأصلي `native loopback`؛ لتحقيق أزمنة أقل نوصي بمشاريع مثل `node-portaudio` أو `obs-studio-node` في نسخة مستقبلية (إعادة كتابة كاملة للمحرك).
- التطبيق **لا يثبّت سائق المايك الوهمي** بنفسه؛ لأنه يحتاج إلى برامج تشغيل موقّعة ومنصّة لكل نظام. التطبيق يكتشف السائق ويوجهك إلى الخطوات، لكن التثبيت نفسه خارج نطاقه:
  - ويندوز: [VB-Audio Virtual Cable](https://vb-audio.com/Cable/)
  - ماك: [BlackHole](https://existential.audio/blackhole/)
- **التوقيع الرقمي**: الحزم غير موقّعة حالياً، لذلك تظهر تحذيرات النظام. للتوقيع الذاتي في `package.json` أضف:
  - ويندوز: `"win": { "certificateFile": "cert.pfx", "certificatePassword": "..." }`
  - ماك: `"mac": { "identity": "Developer ID Application: ..." }`
  ثم شغّل `npm run dist:win` / `dist:mac`.
- **الفحص التلقائي للتحديثات**: يعمل ضد أحدث إصدار في مستودع `moaaz-i/nabra` على GitHub. النشر مفعّل بالفعل في `package.json` (GitHub provider)، ويظهر زر «نسخة جديدة» في شريط الرأس عند توفر إصدار أحدث؛ يُفتح الرابط في المتصفح ولا يُثبَّت تلقائياً. للتعطيل، غيّر `UPDATE_REPO` في `electron/main.ts`.

## خصائص واجهة إضافية

- **مسبقات مخصصة**: «حفظ الحالي كمسبق» يخزن إعداداتك، و«تصدير/استيراد» ينقلها كملف JSON بين الأجهزة.
- **اختصارات قابلة للتخصيص**: لوحة «الاختصارات» في تبويب المحرك؛ اضغط مفتاحاً لتعيين «تشغيل/إيقاف» و«كتم» و«تجاوز» و«ضغط لتتحدث» (PTT).
- **بوابة ضوضاء** و**مضخّم مايك** منفصلان في تبويب «ديناميك».
- **كاشف نغمة** ثلاثي (تلقائي/YIN/MCM) في تبويب «طبقة»، مع خيارين لزمن استجابة التبديل (قياسي/منخفض). نافذة المحرِّك الطوري تُبنى عند بدء التوجيه، فيُنبّه التطبيق إن غيّرت الخيار أثناء التشغيل.
- **عدّاد ضبط حيّ** في لوحة المراقبة: في الوضع التكيّفي يقيس انحرافك عن النغمة المطلوبة، وفي الوضع الثابت يقيسه عن أقرب نصف درجة. ولا يدّعي أي قراءة أثناء الصمت.
- **تسجيل** الناتج مباشرة (webm) من شريط الإجراءات السفلي أثناء عمل التوجيه.
- **الوضع المصغّر** و**إبقاء النافذة في المقدمة** من شريط الرأس.
